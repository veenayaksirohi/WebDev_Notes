## 📝 Overview

**SQL (Structured Query Language)** is a standard language used to **store, retrieve, manipulate, and manage data** in **relational databases**.

A **Relational Database Management System (RDBMS)** stores data in **tables (relations)** consisting of rows and columns, and maintains relationships between tables using keys.

**Popular RDBMS:**

- MySQL
- PostgreSQL
- Oracle
- SQL Server
- SQLite

### Key Concepts (Simple Explanation)

1. **Table** → Like an Excel sheet
2. **Row (Tuple)** → One record
3. **Column (Attribute)** → A field/property
4. **Primary Key** → Uniquely identifies a row
5. **Foreign Key** → Creates relationship between tables

## 🏗️ SQL Syntax Structure

### Basic Rules

- SQL statements end with a **semicolon (`;`)**
- SQL is **case-insensitive** (`SELECT` = `select`)
- Keywords are usually written in **UPPERCASE** (best practice)
- Statements are made of **clauses** like `SELECT`, `FROM`, `WHERE`

### Basic Query Structure

```sql
SELECT column1, column2
FROM table_name
WHERE condition;
```

### Example

```sql
SELECT name, age
FROM users
WHERE age > 18;
```

### Common SQL Clauses

| Clause   | Purpose        |
| -------- | -------------- |
| SELECT   | Choose columns |
| FROM     | Specify table  |
| WHERE    | Filter rows    |
| ORDER BY | Sort results   |
| GROUP BY | Group rows     |
| HAVING   | Filter groups  |

## 🗃️ Data Types

### Common SQL Data Types

| Data Type    | Description            | Example         |
| ------------ | ---------------------- | --------------- |
| INT          | Integer numbers        | `25`            |
| VARCHAR(n)   | Variable-length string | `VARCHAR(50)`   |
| DATE         | Date value             | `2025-12-25`    |
| BOOLEAN      | True / False           | `TRUE`          |
| DECIMAL(p,s) | Fixed-point number     | `DECIMAL(10,2)` |

### Example Table

```sql
CREATE TABLE employees (
  id INT PRIMARY KEY,
  name VARCHAR(100),
  salary DECIMAL(10,2),
  is_active BOOLEAN,
  joining_date DATE
);
```

## 🔄 Interactivity: SELECT Basics

### Select All Columns

```sql
SELECT * FROM users;
```

### Select Specific Columns

```sql
SELECT username, email FROM users;
```

### Filtering with WHERE

```sql
SELECT *
FROM employees
WHERE salary > 50000;
```

### Using LIKE

```sql
SELECT *
FROM users
WHERE name LIKE 'V%';
```

### Using IN

```sql
SELECT *
FROM orders
WHERE status IN ('PENDING', 'SHIPPED');
```

## ✅ Best Practices

- Write SQL keywords in **UPPERCASE**
- Use meaningful table and column names
- Avoid `SELECT *` in production
- Always use `WHERE` with `UPDATE` / `DELETE`
- Format queries for readability

---

## ⚠️ Common Pitfalls

- Forgetting `WHERE` clause → affects all rows
- Using wrong data types
- Confusing `WHERE` vs `HAVING`
- Case sensitivity issues in string comparison
