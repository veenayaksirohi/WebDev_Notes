# 🛣️ Shortest Paths & Advanced Graphs

## 📝 Overview

Advanced graph algorithms for finding optimal paths and spanning trees.

## 🎯 Shortest Path Algorithms

### Dijkstra's Algorithm
- **Use**: Single source, non-negative weights
- **Time**: O((V + E) log V) with min-heap
- **Greedy approach**

### Bellman-Ford Algorithm
- **Use**: Single source, handles negative weights
- **Time**: O(V × E)
- **Detects negative cycles**

### Floyd-Warshall Algorithm
- **Use**: All-pairs shortest paths
- **Time**: O(V³)
- **Dynamic programming**

## 🌲 Minimum Spanning Tree (MST)

### Prim's Algorithm
- **Greedy**: Start from vertex, grow tree
- **Time**: O((V + E) log V) with heap
- **Similar to Dijkstra**

### Kruskal's Algorithm
- **Greedy**: Sort edges, add if no cycle
- **Time**: O(E log E)
- **Uses Union-Find**

## 🔗 Advanced Topics

### Disjoint Set (Union-Find)
- **Operations**: Union, Find
- **Time**: O(α(n)) ≈ O(1) with path compression
- **Use**: Detect cycles, connected components

### Bridges
Edges whose removal disconnects graph

### Articulation Points
Vertices whose removal disconnects graph

## 🔍 Interview Questions

| #   | Question                              | Pattern                              |
| --- | ------------------------------------- | ------------------------------------ |
| 1   | Network delay time                    | Dijkstra's algorithm                 |
| 2   | Cheapest flights within k stops       | Modified Dijkstra/Bellman-Ford       |
| 3   | Minimum spanning tree                 | Prim's or Kruskal's                  |
| 4   | Number of connected components        | Union-Find                           |
| 5   | Critical connections                  | Tarjan's algorithm (bridges)         |
