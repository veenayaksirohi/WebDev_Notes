# 🎲 Dynamic Programming & Greedy

## 📝 Overview

Optimization techniques for solving complex problems by breaking them into subproblems.

## 🧩 Dynamic Programming Fundamentals

### Key Properties
1. **Overlapping Subproblems**: Same subproblems solved multiple times
2. **Optimal Substructure**: Optimal solution contains optimal solutions to subproblems

### Techniques

#### Memoization (Top-Down)
- Recursive with caching
- Store computed results

#### Tabulation (Bottom-Up)
- Iterative approach
- Fill table from base cases

## 📊 Classic DP Problems

### 1D DP
- Fibonacci
- Climbing stairs
- House robber

### 2D DP
- Longest Common Subsequence (LCS)
- Edit distance
- 0/1 Knapsack

### State Design
Define states, transitions, and base cases

## 💰 Knapsack Problems

### 0/1 Knapsack
Each item used once or not at all

### Unbounded Knapsack
Unlimited quantity of each item

### Subset Sum
Find subset with given sum

## 🎯 Greedy Algorithms

### Greedy Choice Property
Local optimal choice leads to global optimal

### Classic Problems
- Activity selection
- Interval scheduling
- Huffman coding
- Fractional knapsack
- Minimum spanning tree (Prim's, Kruskal's)
