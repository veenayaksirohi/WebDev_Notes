## 📝 Overview

Arrays and strings are the bread-and-butter of coding interviews. Mastery of traversal patterns, index math, two-pointers, sliding windows, and basic bit & math tricks will let you solve a large portion of medium-level problems quickly and correctly.

---

## 🔢 1D Arrays

### Traversal

* Iterate left-to-right or right-to-left: `for i in range(n)` or `for x in arr`.
* Common patterns: single pass, two-pass (prefix/suffix), nested loops for pairwise comparisons.

**Example — sum of array**

```python
s = 0
for x in arr:
    s += x
```

### Insertion & Deletion (array vs dynamic array)

* Fixed-size arrays: insertion/deletion in middle is `O(n)` (shift elements).
* Dynamic arrays (Python `list`, Java `ArrayList`): amortized `O(1)` append, `O(n)` insert/delete at arbitrary positions.

**Example — remove element at index i (shift)**

```python
for j in range(i, n-1):
    arr[j] = arr[j+1]
n -= 1
```

### Prefix / Suffix ideas (prefix sums, suffix arrays)

* Prefix sum lets you answer range-sum queries in `O(1)` after `O(n)` preprocess.

```python
prefix = [0]*(n+1)
for i in range(n):
    prefix[i+1] = prefix[i] + arr[i]
# sum arr[l:r] = prefix[r] - prefix[l]
```

* Suffix arrays (or suffix sums) similar but from the end.

## 🔲 Multi-dimensional Arrays (2D / 3D)

### Matrix representation & indexing

* 2D array `mat` with `m` rows and `n` cols: element at row `r`, col `c` is `mat[r][c]` (0-based).
* Linear index to 2D: `idx = r * n + c`; reverse: `r = idx // n`, `c = idx % n`.

### Row / Column operations

* Row-wise scans are cache-friendly; column-wise may be slower in row-major languages.
* Common operations: transpose, rotate matrix, sum rows/columns.

**Example — transpose in-place (square matrix)**

```python
for i in range(n):
  for j in range(i+1, n):
    mat[i][j], mat[j][i] = mat[j][i], mat[i][j]
```

### Common grid problems & patterns

* **Neighbors**: 4-dir `[(0,1),(0,-1),(1,0),(-1,0)]` or 8-dir for diagonals.
* **BFS/DFS on grid**: used for shortest path on unweighted grid, connected component count.
* **Flood fill**, **island counting**, **matrix path DP (min path sum)**.

**Example — BFS template**

```python
from collections import deque
q = deque([(sr, sc)])
visited = set([(sr, sc)])
while q:
  r, c = q.popleft()
  for dr, dc in dirs:
    nr, nc = r+dr, c+dc
    if valid(nr, nc) and (nr,nc) not in visited:
      visited.add((nr,nc))
      q.append((nr,nc))
```

## 🔤 Strings

### Basic manipulation

* Concatenation, slicing, splitting, joining, replacing — complexity depends on language (strings immutable → concatenation can be `O(n)`).
* Use lists/builders for repeated concatenation.

**Palindrome check**

```python
s == s[::-1]
```

### Sliding window patterns

* Use when looking for subarrays/substrings with constraints (sum, unique count, length).
* Two pointers maintain window boundaries; expand/contract based on condition.

**Example — longest substring with K distinct chars (sketch)**

```python
l = 0
counts = {}
for r in range(len(s)):
  counts[s[r]] = counts.get(s[r],0)+1
  while len(counts) > K:
    counts[s[l]] -= 1
    if counts[s[l]] == 0: del counts[s[l]]
    l += 1
  ans = max(ans, r-l+1)
```

### Palindrome checks & expansions

* Expand-around-center technique `O(n^2)` worst, `O(n)` for Manacher’s algorithm.

## 🔀 Two-pointers technique

* Use two indices `i, j` starting at ends or start; move inward or based on conditions.
* Use-cases: sorted-array pair-sum, remove-duplicates in-place, partitioning.

**Example — two-sum in sorted array**

```python
i, j = 0, n-1
while i < j:
  s = arr[i] + arr[j]
  if s == target: return (i,j)
  if s < target: i += 1
  else: j -= 1
```

## 🔢 Math & Bit Basics

### GCD / LCM / Primes

* GCD using Euclid’s algorithm `O(log min(a,b))`:

```python
def gcd(a,b):
  while b:
    a, b = b, a%b
  return a
```

* Sieve of Eratosthenes for primes up to `n` — `O(n log log n)`.

### Bit operations & tricks

* `&`, `|`, `^`, `~`, `<<`, `>>` — constant-time bit ops.
* Common tricks:

  * `x & -x` isolates lowest set bit.
  * Check power of two: `x & (x-1) == 0` (and `x>0`).
  * Swap with XOR: `a ^= b; b ^= a; a ^= b` (rarely useful in high-level languages).

## ✅ Best Practices

* State complexity (time & space) clearly when explaining solutions.
* Use zero-based indexing and be consistent in examples.
* Prefer in-place solutions when required but consider readability.
* For strings, avoid repeated concatenation in loops — use builders.

---

## ⚠️ Common Pitfalls

* Off-by-one errors in loops and slicing ranges.
* Mutating lists while iterating them.
* Ignoring edge cases: empty array, single element, all-equal elements, NULLs.
* Assuming random access is cheap in linked structures (it isn’t).
