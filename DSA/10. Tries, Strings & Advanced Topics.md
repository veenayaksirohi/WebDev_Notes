# 🔤 Tries, Strings & Advanced Topics

## 📝 Overview

Advanced data structures and algorithms for string processing and specialized problems.

## 🌳 Tries (Prefix Trees)

### Structure
- Tree where each node represents a character
- Root represents empty string
- Path from root to node = prefix

### Operations
- **Insert**: O(m) where m = word length
- **Search**: O(m)
- **StartsWith**: O(m)

### Use Cases
- Autocomplete
- Spell checker
- IP routing
- Word search games

## 🔍 String Algorithms

### KMP (Knuth-Morris-Pratt)
- Pattern matching in O(n + m)
- Uses LPS (Longest Prefix Suffix) array

### Z-Algorithm
- Find all occurrences of pattern
- Time: O(n + m)

### Rabin-Karp
- Rolling hash for pattern matching
- Average: O(n + m)

## 📊 Advanced Data Structures

### Segment Tree
- Range queries and updates
- Build: O(n), Query: O(log n), Update: O(log n)
- Use: Range sum, min/max queries

### Fenwick Tree (BIT)
- Prefix sum queries
- Space efficient: O(n)
- Query/Update: O(log n)

### Suffix Array
- Sorted array of all suffixes
- Pattern matching, LCP
