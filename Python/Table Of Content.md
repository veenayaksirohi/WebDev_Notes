# 🐍 Python Notes — Table of Contents

A comprehensive guide to Python fundamentals and advanced topics for interview preparation and practical application.

---

## 📚 Course Structure

### [[01-Python_Basics_&_Fundamentals|1. Python Basics & Fundamentals]]

- **Overview**: Introduction to Python and its core strengths
- **Language structure**: Syntax, indentation, and semantics
- **Data handling**: Variables, data types (integers, floats, strings, booleans)
- **Operators**: Arithmetic, comparison, logical, bitwise operations
- **Interactivity**: Input and output functions (`print`, `input`)

### [[02-Control_Flow|2. Control Flow]]

- **Decision-making**: Conditional statements (`if`, `elif`, `else`)
- **Looping constructs**: `for` and `while` loops
- **Loop control**: `break`, `continue`, `pass`

### [[03-Data_Structures|3. Data Structures]]

- **Core containers**: Lists, tuples, sets, dictionaries
- **String manipulation**: Common string operations and methods
- **Comprehensions**: List, dictionary (and possibly set) comprehensions

### [[04-Functions_&_Functional_Programming|4. Functions & Functional Programming]]

- **Functionality**: Defining and calling functions
- **Arguments**: Positional, keyword, default, `*args`, `**kwargs`
- **Lambda functions**: Anonymous functions
- **Higher-order tools**: `map`, `filter`, `reduce`
- **Functional patterns**: Closures and decorators

### [[05-Modules,_Packages,_and_Standard_Library|5. Modules, Packages, and Standard Library]]

- **Importing & organizing**: Modules
- **Built-in libraries**: `math`, `datetime`, etc.
- **Custom modules/packages**
- **Environment management**: Virtual environments, `pip`, `conda`

### [[06-Error_Handling_and_File_IO|6. Error Handling and File I/O]]

- **Exception handling**: `try`, `except`, `finally`, raising exceptions
- **File operations**: Read/write text, CSV, JSON

### [[07-Object-Oriented_Programming_(OOP)|7. Object-Oriented Programming (OOP)]]

- **Class design**: Defining classes & instantiating objects
- **Attributes & methods**: Instance variables, class variables, methods
- **Lifecycle**: Constructors (`__init__`), destructors
- **Principles**: Inheritance, polymorphism, encapsulation, abstraction
- **Magic (dunder) methods**: `__str__`, `__len__`, etc.
- **Advanced OOP**: Class methods, static methods, metaclasses

### [[08-Iterators,_Generators_&_Context_Managers|8. Iterators, Generators & Context Managers]]

- **Iterable protocols**: Building and using iterators
- **Generators**: Using `yield`
- **Context managers**: `with` statement, `__enter__`/`__exit__`

### [[09-Advanced_Python_Concepts|9. Advanced Python Concepts]]

- **Advanced function patterns**: Decorators, descriptors, properties
- **Abstract Base Classes (ABC)**
- **Type annotations**: `typing` module
- **Internals**: Memory management, garbage collection
- **Meta-programming**: Metaclasses
- **Asynchronous programming**: `asyncio`, `await`
- **Concurrency**: Threading, multiprocessing

### [[10-Python_Internals_(Bonus_Expert)|10. Python Internals (Bonus / Expert)]]

- **Bytecode & execution model**
- **CPython and alternative implementations**
- **C extensions & Cython**
- **Advanced meta-programming**
- **Memory model & garbage collection (deep dive)**
